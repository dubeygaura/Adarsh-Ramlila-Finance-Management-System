# आदर्श रामलीला समिति – वित्त प्रबंधन प्रणाली

A professional web-based Financial Management System designed for managing the income, expenses, transactions, members, and financial reports of Adarsh Ramlila Samiti, Bansapur.

## 📌 Project Overview

The Adarsh Ramlila Finance Management System is a responsive web application developed to digitally manage the financial activities of a Ramlila committee.

The system provides a simple and user-friendly dashboard for administrators to monitor income, expenses, balance, transactions, reports, and committee members.

## ✨ Features

- 🔐 Secure Login Interface
- 📊 Financial Dashboard
- 💰 Income Management
- 💸 Expense Management
- 📋 Transaction Management
- 🔎 Transaction Search
- 📈 Income & Expense Overview
- 📑 Financial Reports
- 👥 Committee Member Management
- 🔔 Notification Interface
- 🚪 Logout Functionality
- 📱 Responsive Design
- 🇮🇳 Hindi/Devanagari User Interface

## 🖥️ Dashboard

The dashboard provides an overview of:

- Total Income
- Total Expenses
- Available Balance
- Total Transactions
- Monthly Income & Expense
- Recent Transactions
- Quick Actions

## 💰 Income Management

Administrators can record income details such as:

- Date
- Amount
- Description
- Category

Supported income categories include:

- Donation
- Sponsorship
- Contribution
- Other

## 💸 Expense Management

The system allows administrators to record committee expenses.

Expense categories include:

- Decoration
- Stage
- Promotion
- Food
- Other

## 📋 Transaction Management

Users can view financial transactions with details such as:

- Date
- Description
- Category
- Transaction Type
- Amount
- Status

The transaction search feature allows users to quickly find specific records.

## 📊 Financial Reports

The Reports section provides an overview of:

- Total Income
- Total Expenses
- Total Balance

The application also provides an interface for downloading financial reports.

## 👥 Committee Members

The system includes a dedicated members section to display committee members and their roles.

Example roles:

- Manager
- President
- Treasurer
